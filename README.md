# 个人财务选择权计算器

一个纯静态单页 HTML 计算器，用于模拟：

- 起薪与年平均涨薪
- 简化税后收入
- 储蓄率沉淀
- 每月定投标普 500
- 5 年 / 10 年资产差异
- 自动生成解释报告

## 在线访问

开启 GitHub Pages 后访问：

```text
https://hawtim.github.io/personal-finance-calculator/
```

## GitHub Pages 开启方式

1. 进入仓库 `Settings`
2. 找到 `Pages`
3. Source 选择 `Deploy from a branch`
4. Branch 选择 `main`
5. Folder 选择 `/root`
6. 保存

## 模型说明

默认计算链路：

```text
起薪 → 年涨薪 → 税后收入 → 储蓄沉淀 → 月度定投 → 5 年 / 10 年报告
```

核心公式：

```text
第 n 年月薪 = 起薪 × (1 + 年涨幅) ^ (n - 1)
年税前收入 = 当年月薪 × 12
年税后收入 = 年税前收入 - 个税
年度储蓄额 = 年税后收入 × 储蓄率
月收益率 = (1 + 年化收益率) ^ (1 / 12) - 1
资产余额 = 上月资产余额 × (1 + 月收益率) + 当月投入
```

## 注意

这是资产路径模拟器，不是精确报税工具。

默认个税模型是简化口径：

- 年免征额 60,000 元
- 不计社保
- 不计公积金
- 不计专项附加扣除
- 不计年终奖
- 不计股票收入

标普 500 收益率是历史或假设输入，不代表未来收益承诺。
